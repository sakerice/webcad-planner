# 費用なしのローカル確認

この隔離アダプターは原版アプリの確認UIを使い、公開fixtureの読み取り済み結果を再生する。新しい画像読み取り、AI、共有、外部APIは接続しない。v3画像読み取りゲートを有効にしない。

```sh
python3 local-preview/server.py
```

出力された `LOCAL_PREVIEW_URL` を新しいブラウザタブで開く。固定ポートが必要なら `WEBCAD_PREVIEW_PORT=65235` を指定する。既存タブに未保存の編集がある場合はそのタブを再読み込みしない。この確認環境も通常のローカル保存を使うため、元の案へサンプルを追記する確認は内容を見て判断する。

通常起動ではサンプル操作を表示しない。読み取り済みサンプルを再生する場合だけ URL に `?sampleReplay=1`（既存queryがあれば `&sampleReplay=1`）を付け、既存の「間取り図から下書き」パネルを開く。AI・共同編集・外部APIの無効化はどちらの起動でも保持する。

「読み取り済み3階サンプルを確認」→各階の元図面・対応点・位置合わせ確認→部分適用→通常2D/3D→Undo。浴槽・玄関・家具の置き換えは明示確認する。階段の表示高さ・順番は未実測の表示仮定で、階接続・床開口は作らない。元サンプルに柵の端点はなく、柵を自動追加しない。実図面精度、屋根、階高、階段接続、床開口は完成と扱わない。

既存ヘッダーの「案を比較」は、通常編集と同じ共通プラン一覧・同じプランIDを使う比較画面を別タブで開く。未保存の編集を保全し、別IDへ自動コピーしない。比較上部は「開く」「新規」、1画面／2画面、画角同期・位置合わせの共通操作だけ。案の切替・保存・複製・履歴・JSON出力／読込・視点は各案の既存ヘッダーを使う。保存読込はその案の既存ツールパネルにある。最大4案の作業対象を保持し、同時表示は2画面まで。3/4案目は共通の「開く」「新規」と各案の切替欄で扱う。画角同期は各案の階数・2D/3Dモード・表示条件を変更しない。通常起動も比較起動も assets/js/plan-library.js を使用し、古い local-preview/plan-library.js は注入しない。

ビルドが必要な場合はスクリプトを確認して `SKIP_DEPLOY=1` を必ず指定する。サーバー起動にビルドや秘密情報は必要ない。

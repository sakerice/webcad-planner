# 費用なしのローカル確認

この隔離アダプターは原版アプリの確認UIを使い、公開fixtureの読み取り済み結果を再生する。新しい画像読み取り、AI、共有、外部APIは接続しない。v3画像読み取りゲートを有効にしない。

```sh
python3 local-preview/server.py
```

出力された `LOCAL_PREVIEW_URL` を新しいブラウザタブで開く。固定ポートが必要なら `WEBCAD_PREVIEW_PORT=65235` を指定する。既存タブに未保存の編集がある場合はそのタブを再読み込みしない。この試作も通常のローカル保存を使うため、元の案へサンプルを追記する確認は内容を見て判断する。

「読み取り済み3階サンプルを確認」→各階の元図面・対応点・位置合わせ確認→部分適用→通常2D/3D→Undo。浴槽・玄関・家具の置き換えは明示確認する。階段の表示高さ・順番は未実測の表示仮定で、階接続・床開口は作らない。元サンプルに柵の端点はなく、柵を自動追加しない。実図面精度、屋根、階高、階段接続、床開口は完成と扱わない。

比較ボタンで通常編集画面を2つ並べる。上部は比較セット・案構成・画角同期だけ。各案の保存/保存読込/JSON出力/JSON読込は、そのパネルの既存ヘッダーを横スクロールして使う。「この案の操作」や上部の単案JSON入力は置かない。最大4案を保持し、3/4案目は「空の案を追加」→パネルの案を切替→そのパネルでJSONを読込。元編集はコピーして比較する。同期するのは画角で、階数や2D/3Dモードは各案が個別に持つ。

ビルドが必要な場合はスクリプトを確認して `SKIP_DEPLOY=1` を必ず指定する。サーバー起動にビルドや秘密情報は必要ない。

# Codex への依頼: 三人称ウォークスルーの人物2人（デザイン → Meshy で立体化・骨組み・動き）

依頼日: 2026-10-13 / 依頼者: Claude（webcad-planner の実装担当）
Issue Kanban の sourceId: `webcad-planner/walk-characters-2026-10-13`

## 何に使うか

webcad-planner（住宅の間取り・3Dプランナー、本番 https://cad-planner.srapps.us ）に、人物の後ろから見ながら家の中を歩く
「三人称のウォークスルー」を作っている（PR #97、隠しスイッチ `?tps=1` の裏）。いまの人物は丸と棒の仮の人形で、
利用者から「簡易すぎてシミュレーションにならない」と言われた。家の広さ・天井の高さ・家具との大きさの関係が分かる、
ちゃんとした人物を **男女1人ずつ** 作る。

アプリへの組み込み（読み込み・歩く動きの再生・大きさ合わせ）は Claude が行う。**この依頼では人物の GLB を作って納めるところまで。**

## 進め方

1. **キャラクターデザイン（画像生成）**: 下の「デザインの方向」で、男女それぞれの三面図（正面・横・背面、全身、A ポーズ、無地の背景）を作る
2. **Meshy で立体化**: Codex アプリのブラウザで Meshy（https://www.meshy.ai/ 、ログイン済みのはず）を開き、三面図から 3D を生成する
   （Image to 3D。複数視点の入力が使えるなら正面・横・背面を入れる）
3. **骨組みと動き**: Meshy の自動リギング（人型）をかけ、**待機（idle）** と **歩く（walk、その場で足踏みする形 = in place）** の2つの動きを付ける。
   座る（sit）が選べるなら3つ目に付ける（任意）
4. **書き出し**: 骨組みと動きを含んだ GLB で書き出す。動きが別ファイルになる場合は、1つの GLB にまとめる（Blender で結合してよい）

## デザインの方向

- 参考: 家庭用ゲーム機の、アニメ調で頭身がやや低めのプレイヤーキャラクター（利用者が見せた例は、ポケットモンスター ソード・シールドの主人公の着せ替え）。
  **雰囲気だけを参考にし、特定の作品のキャラクター・服・ロゴ・模様を写さない。** 作品名やキャラクター名を生成の指示に入れない
- 年齢は大人（20〜30代）。住宅の住まい手として自然な、**家の中で着る普段着**（例: 男性 = ニットとチノパン、女性 = カーディガンとロングスカート）。
  靴は室内なので靴下かルームシューズ
- 頭身は 6〜6.5 頭身程度（アニメ調だが、家具との大きさの関係が読める程度に大人の体格）。身長は **男性 1.72m・女性 1.60m** で作る
- 色は落ち着いた中間色。肌・髪・服の部位がはっきり分かれる塗り分け
- 顔は小さめの表情で、どの家の雰囲気（標準・洋館・古民家）に置いても浮かないこと

- 途中の別案や大量の画像はリポジトリに入れない（採用した物と、比べた候補のうち数枚まで）

## GLB の決まり

- 単位はメートル。原点は**両足の間の床**。上は +Y。正面の向きは +Z（Meshy の既定が違えば、納品メモに書けばよい）
- 身長（頭の頂点）は男性 1.72m・女性 1.60m（±2%）
- 三角形は1人 **3万以下**（多ければ Meshy の減らす機能か Blender の Decimate で減らす）。テクスチャは 2048px 以下
- 骨組みは人型（腰・背骨・首・頭・両腕・両脚）。動き（アニメーションクリップ）の名前は `idle`・`walk`（あれば `sit`）にする
- `walk` は**その場で足踏み**（体が前へ進まない）。1歩の長さと1周期の時間を納品メモに書く（アプリ側で歩く速さと合わせるため）
- 確認画像: 正面・横・背面の静止画と、walk の数コマ（体が前へ流れていないこと、足が床を突き抜けないこと）

- PR の本文に納品メモ: ID・身長の実測・三角形数・テクスチャの大きさ・骨の数・動きの名前と長さ・1歩の長さ・向き・検査の結果。
  **実施していない検査は「していない」と書く**

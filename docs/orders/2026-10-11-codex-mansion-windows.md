# Codex への依頼: 洋館の窓4点

## 何に使うか

webcad-planner（住宅の間取り・3Dプランナー、本番 https://cad-planner.srapps.us ）の「壁・床・屋根を洋館風にする」で、
外壁をレンガにしても**窓だけ現代のアルミの引き違い窓のまま**残る。窓の開口に差し込める洋館の窓を足し、切り替えで窓も替える。

アプリへの組み込み（manifest への登録、窓の選択肢、切り替えで替える処理）は Claude が行う。**この依頼では素材を作って納めるところまで。**

## アプリでの使われ方（形を決める前に読む）

- 窓のモデルは**窓1台ぶん丸ごと**（外枠・障子の框・格子・ガラス・窓台の水切り）。壁と開口はアプリが作る
- 開口の大きさに合わせて**縦横に伸縮される**（腰窓は幅 600〜1800mm・高さ 900〜1400mm 程度、掃き出しは高さ 2000〜2200mm）。
  **±30% 伸ばしても破綻しない意匠**にする（格子の本数は固定なので、伸びても格子の比率が崩れすぎないこと）
- 正面は **+Z = 屋外側**（Blender の -Y）。原点は**下端の中心**。単位はメートル
- 寸法はバウンディングボックスを下の表にぴたりと合わせる。奥行きは窓台・額縁の出を含む
- 決まりの詳細は `tools/blender/README.md` の「カタログのモデルを作るときの約束」に従う（`model_kit.run()` を通す、UV を展開する、`.blend` の原本を残す）。面数は1点 **8,000 三角形以下**

### 色を変えられる部位（finishChannel）

- 枠・框・格子: `paint`（白塗りの木部）
- 金物（引手・クレセント・蝶番）: `metal`
- ガラス: 部位は付けない。マテリアル名を `Glass` にし、色 #dfe8ea・不透明度 0.25 前後（alphaMode BLEND）

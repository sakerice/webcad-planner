## 何に使うか

webcad-planner（住宅の間取り・3Dプランナー、本番 https://cad-planner.srapps.us ）の次の2つに使う。

- **扉:** 洋館の室内ドアと玄関ドアを選べるようにし、「壁・床・屋根を洋館風にする」で建具も洋館の扉に替える → **扉板のモデル5点**
- **屋根:** 屋根の素材が「瓦・ガルバ（黒）・スレート」の3つしか無く、選択肢が足りない。和風・洋風の住宅でよく使う屋根材を足す → **屋根のテクスチャ7種**

アプリへの組み込み（manifest への登録、扉の選択肢、屋根の素材の登録）は Claude が行う。**この発注では素材を作って納めるところまで。**

## ブランチと PR の切り方（必ず守る）

```sh
git fetch origin
git switch -c codex/mansion-doors-roof-textures-20261010 origin/main
```

- **必ず最新の `origin/main` から切る。** 他の枝（`claude/*`、`codex/*`）を土台にしない
- PR の宛先（base）は **`main`**。下書き（Draft）で作り、全部そろったら下書きを外す
- 下書きを外す前に、もう一度 `origin/main` に追従する（`git fetch origin && git rebase origin/main`）
- `main` には push しない。マージ・デプロイもしない（main への反映は本番の公開になるので、人が許可してから Claude が行う）
- PR は1つにまとめる。追加のコミットは同じ枝に積む
- **この発注書ファイルはリポジトリに入れない。** 納品メモは PR の本文に書く（前回は同じファイルを双方で足して衝突した）

## A. 扉板のモデル5点

### アプリでの使われ方（形を決める前に読む）

- アプリは**扉の枠・沓摺・丁番の軸は自分で描く。** モデルは**扉板（戸そのもの）と、扉に付く金物**だけにする。枠・額縁・壁は付けない
- 扉板は開口の大きさに合わせて**伸縮される**（室内ドアは幅 600〜900mm・高さ 2000mm まで、玄関は幅 800〜1000mm・高さ 2300mm 前後）。
  **縦横に ±20% 伸ばしても破綻しない意匠**にする（丸い窓・円形のメダリオンのように伸ばすと楕円になる飾りは大きくしない）
- 丁番の位置で回る。**丁番は -X 側の縁、取手（ノブ・レバー）は +X 側**に付ける。取手は表裏の両面に付ける
- 正面は **+Z**（Blender の -Y）。原点は**下端の中心**。単位はメートル
- 寸法はバウンディングボックス（取手の出っ張りを含む）を下の表にぴたりと合わせる

決まりの詳細は `tools/blender/README.md` の「カタログのモデルを作るときの約束」に従う（`model_kit.run()` を通す、UV を展開する、`finishChannel` を付ける、`.blend` の原本を残す）。
ただし面数は洋館セットの水準（1点 **12,000 三角形以下**）でよい。

### 色を変えられる部位（finishChannel）

- 扉板の木部・塗装部: `wood`
- 金物（真鍮・鉄）: `metal`
- ガラス: 部位は付けない。マテリアル名を `Glass` にし、色 #dfe8ea・不透明度 0.25 前後（alphaMode BLEND）

## B. 屋根のテクスチャ7種

### 共通の決まり（前回の洋館のテクスチャと同じ）

- 1枚 **1024×1024px**、上下左右に**継ぎ目なく繰り返せる**こと
- 1種につき3枚: `<key>_diffuse.jpg`（色・sRGB）・`<key>_normal.jpg`（OpenGL 形式 = 緑が上・リニア）・`<key>_roughness.jpg`（白=つや消し・リニア）。JPEG 品質 85 前後
- **1タイルは正方形。** 実寸の何mm角かを決め、その寸法ちょうどの1タイルとして作る。部材の寸法は、タイルに整数個で収まるよう **±10% まで**調整してよい（調整したら納品メモに書く）
- **向き:** 軒先が画像の下、棟が上。瓦の段（横の列）は画像の横方向に並べ、上の段が下の段に重なる向きにする。立平・一文字の縦のはぜは画像の縦方向
- 色は落ち着いた実物の色。独自に作る（手続き生成・ベイク）。写真や外部素材は使わない
- 2×2 に並べた確認画像を `tools/blender/roof_textures/tiling/<key>.jpg` に置く

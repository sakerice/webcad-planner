# Codex への依頼: クラシックセダンのフェンダーの直し（PR #89 の続き）

依頼日: 2026-10-10 / 依頼者: Claude（webcad-planner の実装担当）

PR #89 のクラシックセダン（`rpg-mansion-classic-sedan-01`）は、寸法・向き・接地・色の部位とも問題なく、
アプリに組み込んで家具の差し替え（駐車中の車 → このセダン）にも使っています。**フェンダーの前後の端だけ直してください。**

## 直してほしいこと

**フェンダーの前端・後端が、平らな板のまま外へ跳ね出して「ひれ」に見える。**

- 前のフェンダー: 前端がヘッドライトより前・外へ、薄い板のまま斜めに突き出している（3Dで斜め前から見ると翼のよう）
- 後ろのフェンダー: 後端が後ろのバンパーの外へ、同じく薄い板のまま突き出している
- 1930年代の実車では、フェンダーの端は**下へ巻き込んで丸く閉じる**（端の板が地面の方へ回り込み、厚みのある丸い縁で終わる）。
  板の切り口や、外へ反り上がる先端は見えない

直し方の目安:
- 前フェンダーの前端は、ヘッドライトの台座のすぐ前で下へ回り込んで終える。バンパーより前に出さない
- 後ろフェンダーの後端は、後ろのバンパーの手前で下へ回り込んで終える。車体の幅（1750mm）の外へ跳ねさせない
- 端は面で閉じる（板の切り口を見せない）。車体の他の縁と同じ丸み
- フェンダーの断面（タイヤを覆う丸み）・ステップ・タイヤとの隙間は今のままでよい

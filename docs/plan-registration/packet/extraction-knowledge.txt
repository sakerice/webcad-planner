# 日本の住宅の平面図を読む

910mm を基準とする寸法体系は一例であり、異なる寸法体系の住宅もある。
読めない値は図の寸法・縮尺などの根拠がある場合だけ推定してよい。
以下は読み方を説明する架空の例で、入力図面の寸法・座標・室名ではない。

## 例1 寸法線の内訳に .5 で終わる値が現れる

    架空例の総寸法 3,000
    内訳   625.5 / 874.5 / 1,500

小数を含む値も正当な寸法であり、丸めたり捨てたりせずに足す。
この架空例では内訳の合計が総寸法 3,000 と一致する。

寸法の文字に補助線が重なって読み取れないことがある。読めない箇所が1つだけなら、
その寸法は総寸法との差で決まる。

    架空例の総寸法 3,000
    内訳   625.5 / (読めない) / 1,500
    → 読めない箇所の算出値は 3,000 - 2,125.5 = 874.5

算出値は印字を読めた値とは区別して記録する。

## 例2 壁と、壁ではないもの

壁は、平行な2本の線の間を塗った厚さ 105〜150mm の帯として描かれる。

浴室の中の角の丸い矩形は浴槽の輪郭であり、壁ではない。便器・洗面台・流し台・
ベッド・ソファの輪郭、収納の中のハンガーパイプ、棚の点線、床の目地、
階段の段も壁ではない。

## 例3 長方形ではない部屋

上側が広く下側が狭いL字の区画は、重ならない長方形2つで表す。
左右方向を x左 < x中 < x右、上下方向を y上 < y中 < y下 とすると、

    上の長方形: x左〜x右、y上〜y中
    下の長方形: x左〜x中、y中〜y下

これらは同じ部屋の parts とし、接する辺に壁を足さない。
記号は説明用で、出力には入力図面から求めた実際の数値と室名を使う。

L字・コの字・凸型のどれも同じように表せる。長方形の数に上限は無い。

## 例4 室名が書かれていない部屋

浴槽のある部屋に「浴室」と書かれていないことがある。洗面所・トイレ・階段室・
廊下・玄関も同様に、室名が書かれないことがある。

## 例5 建具の記号

| 描かれ方 | 建具 |
|---|---|
| 1/4円の弧と1本の線 | 開き戸 |
| 壁に平行な2本の線と矢印 | 引戸 |
| 折れ曲がった線 | 折戸 |
| 壁の中の細い2〜3本の線 | 窓 |
| 外周の壁にある開き戸で、外にポーチ・土間・スロープがある | 玄関ドア |

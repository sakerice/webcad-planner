# house-planner mobile 取り込みデータ仕様

## 単位

- 長さ: ミリメートル
- 角度: 度。時計回りを正とする

## 座標系

- x は右が正、y は下が正
- 原点 (0,0) はその階の平面図の左上の外角
- 各階は独立したローカル座標系を使い、部屋はその階の width × depth の範囲内に収まる
- 階の位置合わせは読み取り後の別の registration が担う。共通座標に合わせるためにローカル座標や総寸法を変えない

## 全体の構成

    {
      "floors": [ 階, ... ],
      "notes":  [ 文字列, ... ]
    }

notes は、図から読み取れなかった箇所、および他の記載から判断した箇所を
1件1行で記す。

## 階

    {
      "floor": 整数,
      "width": 数値,
      "depth": 数値,
      "dims":  寸法線,
      "rooms": [ 部屋, ... ],
      "items": [ 物, ... ]
    }

| 項目 | 内容 |
|---|---|
| floor | 階数。1階は 1、2階は 2 |
| width | 建物の総幅 |
| depth | 建物の総奥行き |
| dims | その階の寸法線 |
| rooms | その階の部屋 |
| items | その階の建具・階段・設備 |

## 寸法線 (dims)

    {
      "top":    { "total": 数値, "parts": [ 数値, ... ] },
      "bottom": { "total": 数値, "parts": [ 数値, ... ] },
      "left":   { "total": 数値, "parts": [ 数値, ... ] },
      "right":  { "total": 数値, "parts": [ 数値, ... ] }
    }

| 項目 | 内容 |
|---|---|
| top / bottom / left / right | 建物の上辺・下辺・左辺・右辺 |
| total | その辺に印字され、読めた総寸法。無い・読めない場合は null |
| parts | 印字された内訳。上辺・下辺は左から、左辺・右辺は上から。読めない位置は null を残す |

寸法線の数値は壁の芯から芯までの長さを指す。
寸法線が無い辺は null、全辺に無ければ dims を null とする。
内訳の寸法線自体が無ければ parts は null。0・空文字は未知の長さを表さない。
この欄は印字から得た証拠のみ。算出値や推定値の記録先は notes。
width・depth は正の実寸値。floors が空の場合は適用できる読み取り結果が無い。

## 部屋 (rooms)

    {
      "name":  文字列,
      "parts": [ { "x0": 数値, "y0": 数値, "x1": 数値, "y1": 数値 }, ... ],
      "level": 数値
    }

| 項目 | 内容 |
|---|---|
| name | 室名 |
| parts | その部屋が占める長方形。x0 < x1、y0 < y1 |
| level | その階の床から何mm高いか。段差が無ければ 0 |
| use | その部屋が何に使われる部屋か。下の表から1つ |

### level（スキップフロア・小上がり）

同じ階の中で床が持ち上がっている区画がある。スキップフロア、和室の小上がり、玄関の上がり框の段など。**床だけでなく天井も一緒に上がる。** 上限は 2400mm。

段差の下は空間になり、そこが収納になっていることがある（「ハーフ収納」
「床上げ収納」「階段下収納」）。**その収納は段差の下にある別の部屋**として
parts に入れ、level は 0 とする。持ち上がっているのは上の区画のほうである。

level に値を入れるのは、段差の高さが図に記載されている区画だけとする。
記載が無ければ 0 とする。

### use（部屋の用途）

name は図に書かれた文字そのまま、use はその部屋が何であるか。**別のもの。**
書かれた名前だけでは用途が決まらない部屋がある。use は、名前に加えて図に描かれているもの(床の仕上げ、
置かれている物、どこに面しているか)から決める。

| use | 名前 | 中身 |
|---|---|---|
| ldk | LDK | リビング・ダイニング・キッチンが一体の部屋 |
| living | リビング | くつろぐための部屋。食事や調理は別の部屋 |
| dining | ダイニング | 食事のための部屋 |
| kitchen | キッチン | 調理のための部屋 |
| bedroom | 主寝室 | 大人が寝る部屋 |
| kids | 子供部屋 | 子供が寝て、勉強する部屋 |
| washitsu | 和室 | 畳の部屋 |
| study | 書斎 | 仕事や読書のための小さな部屋 |
| entry | 玄関 | 家の出入口と靴を脱ぐ土間 |
| hall | ホール・廊下 | 部屋と部屋をつなぐ通路 |
| stairs | 階段 | 階段のための場所 |
| bath | 浴室 | 湯船とシャワーのある部屋 |
| washroom | 洗面脱衣室 | 洗面台と洗濯機のある部屋 |
| toilet | トイレ | 便器のある部屋 |
| wic | ウォークインクローゼット | 人が入れる衣類の収納 |
| storage | 納戸・パントリー | 物をしまうための部屋 |
| balcony | バルコニー | 屋外に張り出した床 |
| outdoor | 外構 | 建物の外。門柱・庭・駐車スペース |
| other | その他 | 上のどれでもない |

1つの部屋は複数の長方形で表せる。同じ部屋に属する長方形の間に壁は生成されない。
部屋どうしは重ならない。

## 物 (items)

    { "type": 文字列, "x": 数値, "y": 数値, "w": 数値, "d": 数値, "rot": 数値 }

| 項目 | 内容 |
|---|---|
| type | 種類 |
| x, y | その物の中心の座標 |
| w | 幅 |
| d | 奥行き |
| rot | 回転角 |

建具（窓・扉）は最も近い壁に取り付けられ、向きはその壁から決まる。

物は部屋と重なってよい。階段の下がトイレや収納になっている場合、その部屋の上に
階段を置く。

### type に使える値

【建具・開口 — 壁の上に載せる。最寄りの壁へ自動で吸い付くので向きの指定は不要】
  window = 窓（腰窓。床まで届かない窓）既定 1650×150mm
  window-door = 掃き出し窓（床まで届く大きな窓。ベランダや庭へ出られる）既定 1650×180mm
  door-swing = 開き戸（丁番で開く扉。図では1/4円の弧で描かれる）既定 780×780mm
  door-slide-s = 片引き戸（横に滑らせる扉）既定 780×150mm
  door-fold = 折戸（折りたたんで開く扉。収納の前によくある）既定 780×420mm
  door-opening = 開口（建具の無い壁の抜け）既定 780×160mm
  door-front = 玄関ドア（玄関の扉。1階に1つだけ）既定 940×200mm
【階段 — その階から上の階へ上る。その階の図の位置を保持し、いちばん上の階には置かない】
  stair = 階段（直進する階段。段を描いた細長い矩形）既定 910×2730mm
  stair-corner = 階段の廻り部（向きが変わる隅の部分。扇形の段）既定 910×910mm
【水まわりの設備 — 図に描かれているものだけ】
  bath = 浴槽（浴室の中の湯船。角の丸い矩形で描かれる）既定 1600×1600mm
  toilet = 便器（トイレの便器）既定 380×680mm
  sink = 洗面台（洗面化粧台。洗面脱衣室にある）既定 750×560mm
  kitchen = 流し台（キッチンの調理台。細長い矩形）既定 2550×650mm
【屋外 — 建物の外の床。部屋ではなく物として置く】
  balcony = バルコニー（2階以上から外へ張り出した床）既定 1820×910mm

既定は、アプリのカタログにある品物の寸法。

| 種類 | w と d |
|---|---|
| 設備（bath / toilet / sink / kitchen） | 既定の値を用いる |
| 階段（stair / stair-corner） | w は既定の値。d は段数に応じて図から読み取った長さ |
| balcony | 図から読み取った寸法を用いる |
| 建具（window / window-door / door-swing / door-slide-s / door-fold / door-opening / door-front） | 図から読み取った寸法を用いる |

## 図面に描かれていた印 (marks)

家具などの印。**items とは別のもの。**

items は「実際に置く物」で、動かせる家具は入れない（図面の家具はメーカーの
標準仕様の絵であって、置く物ではない）。marks はその判断を変えずに、
**図面に何が描かれていたか**だけを残すためにある。

| 項目 | 中身 |
|---|---|
| x, y, w, d | 位置と大きさ |
| label | その印に添えられた文字。「TV」「クローゼット」「WIC」など。無ければ空 |
| looks | 見たままの形。「細長い薄い矩形」「円と矩形」「弧のある矩形」など |
| guess | それが何だと思うか。下の語から1つ。見当が付かなければ other |

looks と guess は**両方**返す。guess はあなたの判断、looks はその根拠になる。
こちらは日本の住宅の作法（カーテンは窓に付き、幅は窓より左右100〜200mm大きい、
など）を持っていて、guess をそれに照らして確かめる。

guess に使える語: kitchen-unit=システムキッチン / kitchen-storage=キッチン収納 / cooktop=コンロ / range-hood=レンジフード / cooking-appliance=調理家電 / kitchen-sink=シンク / refrigerator=冷蔵庫 / bathtub=浴槽 / shower=シャワー・水栓 / vanity=洗面化粧台 / toilet=便器 / laundry=洗濯・物干し / shoe-storage=玄関収納 / hvac=空調 / utility-equipment=住宅設備機器 / joinery-prop=建具（モデル） / sofa=ソファ / chair=チェア / dining-table=ダイニングテーブル / low-table=ローテーブル / desk=デスク / counter-table=カウンターテーブル / table-set=テーブルセット / bed=ベッド / bedding=寝具 / closet=クローゼット / cabinet=キャビネット / chest=チェスト / shelf=シェルフ / tv=テレビ・AV / appliance=生活家電 / light=照明 / curtain=カーテン / roller-screen=ロールスクリーン / rug=ラグ・カーペット / mirror=ミラー / wall-decor=壁装飾 / decor=小物・装飾 / plant=観葉植物 / kids=キッズ / pet=ペット / gate-post=門柱・ポスト / deck=デッキ・テラス / garden-plant=庭木 / garden-equipment=屋外設備 / fence=フェンス・目隠し / other=その他

## アプリが生成する要素

次の要素はこのデータに含めない。読み取った内容から生成される。

| 要素 | 生成元 |
|---|---|
| 壁 | 部屋と部屋の境目、および部屋と屋外の境目 |
| 基礎 | 1階の部屋の外形 |
| 屋根 | 最上階の部屋の外形に軒の出 450mm を加えたもの |

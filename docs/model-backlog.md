# これから作るモデル — 何を、どの寸法で

`node tools/catalogue_gap.mjs` の不足と `docs/quality-bar.md` のクオリティラインから
起こした、**作る対象の一覧**。そのまま制作の依頼文に使える粒度で書く。

寸法の根拠は、日本の住宅・住宅設備・エクステリアの標準寸法。範囲の検査は
`tools/catalogue-vocab.mjs` の `REAL_SIZE`（該当する分類のみ）。

約束（座標・原点・正面・UV・面数・登録）は `tools/blender/README.md` の
「カタログのモデルを作るときの約束」。**制作を頼むときは、まずそれを渡す。**

---

## 1. 外構 — 済（11点 → 19点）

3Dの外観は、建物より外構で決まる。`docs/quality-bar.md` は
「オープン外構・門柱・黒縦格子・土間コン+スリット目地・タイルアプローチ幅900以上・
駐車2.5×5.0m・シンボルツリー」を求めているが、置ける物が足りない。

| 作るもの | 寸法(mm) | 分類 | なぜ |
|---|---|---|---|
| シンボルツリー（高木・落葉） | 2000×2000×4000 | garden-plant | 庭木が1点だけ。玄関脇の1本で外観が決まる |
| 中木（常緑・目隠し） | 1200×1200×2200 | garden-plant | 隣家との視線を切る。株立ちとは別の形 |
| 低木・下草（まとまり） | 900×900×500 | garden-plant | 足元が土のままだと造成地に見える |
| ウッドデッキ（1間×半間） | 1820×910×450 | deck | 既存1点は2600×900固定。掃き出し窓の幅に合う寸法が要る |
| タイルテラス | 1820×1820×150 | deck | デッキとは別の仕上げ。土間コンとの差 |
| 縦格子フェンス（1スパン） | 1820×60×1800 | （新）fence | **目隠し格子が1点も無い。** quality-bar が名指ししている |
| 駐車場の車止め | 600×100×100 | garden-equipment | 駐車2.5×5.0mの見切り |
| 屋外水栓（立水栓・パン付き） | 300×300×900 | garden-equipment | 既存の garden-tap と別意匠 |

8点とも `tools/blender/build_garden.py` で作り、登録まで済んでいる。
分類 `fence` は `tools/catalogue-vocab.mjs` へ追加し、
`assets/js/room-program.js` の外構プログラムにも「隣地との目隠し」として
入れた（足すまで、作っても誰も要求しない在庫になっていた）。
庭木は1点→3点になったので、要求数も1→3へ上げてある。

## 2. 生活小物 — 済（5点 → 11点）

quality-bar は「リビングに生活小物2点以上」を求めている。1軒で4点要るのに
在庫5点だと、どの家にも同じ小物が並ぶ。

| 作るもの | 寸法(mm) | 分類 |
|---|---|---|
| 本の平積み・立て掛け | 250×180×220 | decor |
| マグカップとトレー | 300×200×110 | decor |
| 花瓶（枝もの・背の高い） | 200×200×600 | decor |
| バスケット（ブランケット入り） | 450×350×380 | decor |
| 卓上の観葉（小鉢） | 180×180×300 | plant |
| ~~掛け時計~~ **作らない** | — | — |

| 玄関の小物（トレーと鍵） | 250×180×120 | decor |

6点とも `tools/blender/build_decor.py` で作り、登録まで済んでいる。

**掛け時計は作らないことにした。** 壁装飾は在庫24点で、うち3点が既に掛け時計。
`node tools/catalogue_gap.mjs` の不足にも載っていない。その枠を玄関の小物へ
回した。小物・装飾は LDK・玄関・和室に置かれる分類だが、在庫5点はすべて洋風の
置物で、**玄関に置けるものが1点も無かった**。

小物は**1点ずつが小さいぶん、数が効く**。面数は各200三角形以内と見積もって
いたが、実際は角を丸めると 500〜1,200 三角形になる。**角張ったまま出すと
紙に見える**ので、ここは削らない。

## 3. 洗濯まわり — 済（2点 → 5点）

| 作るもの | 寸法(mm) | 分類 | なぜ |
|---|---|---|---|
| 洗濯機（ドラム式） | 640×720×1050 | laundry | **洗濯機のモデルが無い**。洗面脱衣室が成立しない |
| 洗濯パン | 640×640×120 | laundry | 洗濯機の下。無いと床に直置きに見える |
| 室内物干し（天井付け・2本） | 1200×60×250 | laundry | 既存の laundry-rail と別形式 |

## 4. エアコン — 済（4点 → 5点）

壁掛け2種を作ったが、1軒に5台要るので、もう1〜2種あると同じ物が並ばない。

| 作るもの | 寸法(mm) | 分類 |
|---|---|---|
| 壁掛けエアコン（コンパクト） | 728×220×280 | hvac |

洗濯まわり3点とエアコン1点は `tools/blender/build_laundry.py` で作り、登録まで
済んでいる。洗濯・物干しの不足は解消した。

**空調はまだ不足のままで、これは在庫の少なさではなく多様性の問題。**
1軒に5台要るので、5点しか無いとどの部屋も同じ機種になる。追加するなら
既存3種と並べて見分けが付く意匠にすること。

## 作る順番

~~外構~~（済） → ~~生活小物~~（済） → ~~洗濯まわり~~（済） → ~~エアコン~~（済）。

**18点すべて作り終えた。** 次に作るものは `node tools/catalogue_gap.mjs` の
不足から起こす。いま残っているのは 空調・庭木・フェンス・デスク。

外構が先なのは、**3Dの外観に効く範囲がいちばん広い**から。内観の小物は
1室ずつにしか効かないが、外構は建物の見え方そのものを変える。

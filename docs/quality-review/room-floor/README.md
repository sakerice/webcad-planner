# 部屋ごとの床上げ（2026-09-08）

部屋プロパティの「床の高さ」で floorRaiseMm（0–600mm）を設定する。未設定は0mmで、既存データの床高を変更しない。玄関0mm・居室150mm・浴室150mmを選択例とする。全国一律の必須寸法ではなく、浴室の納まりは採用製品に合わせて調整する。

寸法参考: LIXIL「上がり框」 https://www.lixil.co.jp/square/articles/025/ （戸建て150–170mmの例）。

床の側面を含めて厚みを増やす。家具と開口、歩行の基準に部屋の床高を反映。階高と天井の位置は維持する。有効天井高は床上げ分を減らす。重複部屋では小さい部屋を優先する。車など地面基準の外構は床上げ対象外。

検証: room-floor / height-model / ceiling-ui / ceiling-finish の74テスト成功。Three.js実行環境で玄関と室内の上面差150mm、家具底面150mm、歩行足元150mm、車0mm、ページ例外なしを確認。entry-living-step.png はこの検証シーン。各上階の床上げが混在する複雑な階段・踊り場は追加検証が必要。

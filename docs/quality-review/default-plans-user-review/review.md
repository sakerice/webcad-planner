# ユーザー編集を起点にした3階建ての改善

基準は提供された `plan (21).json`。受領データを user-edited.json、直前のデフォルトを before.json に保存した。壁42本・部屋23室は維持され、家具・設備等が198点から176点へ減った。変更理由は本人の説明ではなく、差分と配置からの考察である。

## 差分と考察

| 編集 | 配置から読み取れる理由と採用判断 |
|---|---|
| 1Fホールと3Fギャラリーの大型収納を削除 | 通行できる幅だけでは圧迫感を評価できない。階段と吹き抜けへ向かう場所の余白を優先し、再配置しない。 |
| 1Fクローゼット内の大型家具を削除 | 奥行910mmの収納室に奥行773mmの置き家具を重ねる構成は過剰。部屋としての収納スペースを残し、家具を戻さない。 |
| 1F納戸の棚3点、2Fパントリーの棚2点とコーヒーメーカーを削除 | 小さな収納空間を用途の異なる家具で埋めていた。パントリーで抽出作業まで行う設定を撤回。 |
| 2Fトイレの棚を削除 | 最小限の水まわりに棚を足したことによる視覚的な窮屈さを解消。 |
| 浴室・洗面の追加鏡を削除、高窓高さ450→250mm | 別体モデルを足すより壁面を整理する判断。窓上端はFL+2350mmとなる。鏡の削除理由は未確認だが、勝手に復元しない。 |
| リビングの机・椅子・ランプを削除 | 仕事場を追加したことで吹き抜け下の余白を消していた。東側は自由に使える床として残す。 |
| 各子ども室の収納を2台→1台、ラグを削除、ベッドを西へ移動 | 中央の遊び・着替え・椅子を引く場所を広げる。残った幅1mの収納は維持。 |
| 3Fホールの棚と飾りを削除 | 通路に展示場所を設ける必然性が薄い。通り抜けと採光を優先。 |
| ソファ、テーブルと花瓶、観葉植物を移動 | 家具密度を落とし、リビングのまとまりを調整。下記の物理干渉だけ追加修正した。 |
| 冷蔵庫を南へ移動、キッチン開口2730→1990mm | 冷蔵庫の背後・脇に壁面が残る構成を採用。開口は元の左端を保持。 |
| 洋室Bの空調を西壁へ移動 | 内部間仕切りから外壁側へ。寝室間の壁面を整理する。送風・配管負荷の工学的検証をしたという意味ではない。 |
| シーリングファンを着座領域側へ、東側ダウンライト1点を削除 | 机を撤去した領域の照明を減らし、ファンを実際に過ごす場所へ寄せる。 |

## 回転差分の扱い

モデルに付いた `modelFacingVersion:1` とFMP家具の180度回転は、アプリの `normalizeLegacyFurnitureItems` による正面統一を含む。これをユーザーによる配置変更と誤認しない。近隣建物にも同様の移行がある。配置検査側もこのバージョンを認識するよう修正し、旧形式と移行済み形式が同じ正面を示す回帰テストを追加した。

## 追加した改善

- 南東へ移された植物は、低い収納と平面・高さ方向に重なっていた。東壁側の中央寄りへ移し、収納の扉前600mmも空けた。
- 南へ寄せたソファは掃き出し窓前1000mmの通行帯に入っていた。北へ250mm調整し、花瓶とテーブルも一緒に250mm調整。ソファ東側の広い余白は保つ。
- ベッドや空調などの受領済み配置は維持。14.91㎡の吹き抜けも維持。追加家具は0点。
- 生成スクリプトに型・座標を含む変更前オブジェクト全体の照合を入れた。古いIDを別の家具へ誤適用する場合は生成を止める。出力前に照合するので、失敗時もデフォルトファイルを壊さない。

## 検証と判断事項

配置検査43項目のうち42項目が通過。残りは収納率7.4%がツールの目安10〜13%未満という指摘。検査基準を下げたり収納家具を通路へ戻したりせず、この指摘を残した。収納室5.0㎡と家具3.6㎡を延床115.9㎡で割った面積指標であり、空の収納室の実際の棚割り・収納容量を保証する値ではない。造作収納の内部仕様は別途検討が必要。

Python回帰11件が通過。再生成後も22点の削除と最終データの一致を検査。公開先の全階平面図・内観・外観・ウォークスルーは after/ と deployed/ に保存する。画像による表示確認と簡易配置検査は構造・法規適合の証明ではない。

# 規格キッチンの追加（2026-09-14）

既存シンクアイランド／壁付IHカウンターを残し、Blender独自制作の14種類を追加した。

## 調査した寸法体系

LIXIL公式「シエラS 2024仕様プランチェックシート」で壁付I/L型、対面D750/D970、天板高さ800/850/900、左右シンク、IH/ガス、食洗機の選択項目を確認。公式2025カタログの掲載間口2100/2400/2550/2700を参考にした。現行製品の全仕様・発注可否を保証するモデルではない。

- https://www2.biz-lixil.com/files/user/contents/proptool_sheet/mit_ki24005.pdf
- https://webcatalog.lixil.co.jp/iportal/CatalogDetail.do?catalogID=17095910000&designID=oldinter&method=initial_screen&sortKey=&sortOrder=&volumeID=LXL13001
- https://www.lixil.co.jp/lineup/kitchen/shiera/parts/

メーカー画像・CAD・メッシュは使用せず、一般的な寸法体系を参照して独自の形状を作成した。LIXIL製品名をモデル名として使用していない。各BOXの構成はシミュレーター独自の組合せ。

## 追加モデル

- I型2100／2400／2550／2700（奥行650、2550／2700は食洗機あり）
- I型ガス2550・食洗機
- 対面2550・奥行750／970
- シンクBOX900、IHコンロBOX750、食洗機BOX450
- 引出しBOX450／600／750／900

全て天板高850mm。水栓を含む全高は別。I型の間口、対面型の奥行、引出しBOXの間口は配置後の「キッチン構成」プルダウンで変更できる。設備を拡大縮小せず、対応する規格モデルに切り替える。ID・座標・向き・階・高さオフセット・色・艶を保持し、Undo/Redo・ロックに対応する。カタログ一覧から全14種類を選択可能。

既存モデルや既存配置は移行・置換しない。自由寸法のドラッグリサイズは既存アプリの機能として残るが、規格モデルを使用する場合はこのプルダウンまたはカタログを使用する。

## 2026-09-15：食洗機あり／なしの直接選択

全7種の完成キッチンに同寸法の対になるモデルを追加し、計21種類になった。「キッチン構成 → 食洗機」で「なし（収納BOX）／あり（幅450mm）」を選択できる。2100は調理台下450、2400は調理台下750を食洗機450＋収納300として構成。他の完成キッチンは食洗機450と収納450を交換する。単体収納BOX450と食洗機BOX450も相互変更可能。これは独自モデルの構成であり、LIXIL実製品の発注組合せを保証する機能ではない。

同じ間口・奥行で型を切り替え、既存の寸法・位置・回転・色・艶・高さを保持。I型の間口、対面型の奥行を変更しても食洗機の選択を維持する。往復切替・Undo/Redo・ロック・寸法・全モデル読み込みをブラウザで検証。既存配置は明示的に変更した場合のみ切り替わる。

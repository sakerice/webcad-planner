# サイドメニューの全オブジェクト検索

「共通操作」の直後、「敷地」の前に検索欄を集約。家具・住設・外構の各検索欄は廃止し、建具、敷地、壁、部屋、屋根、照明も含めて検索する。現在775種類。

既存の配置ツールから検索対象を構築するため、通常メニューと結果の配置動作は共通。閉じたカテゴリも対象。検索中は結果をカテゴリ名付きで表示し、クリアで元のメニューへ戻す。カテゴリの開閉状態は変更しない。カタログの再読込後も検索文字を保持して対象を更新する。

検索は名前・種類・IDを対象とする部分一致、スペース区切りのAND検索。全角英数字を正規化する。結果なし表示、クリアボタン、Escape、件数の読み上げ、キーボードで選択できる結果ボタンを追加。

Node単体2件通過。ブラウザ回帰で390px・1440pxを確認：検索欄が1つで共通操作の直後にあること、ベッド・基礎・窓・照明を検索できること、全角入力・結果なし・クリア、検索結果からの配置ツール選択を検証。

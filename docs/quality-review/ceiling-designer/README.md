# 既存ビューに統合した天井編集

ブランチ: `claude/implementation-handoff-cd3850`。本番未反映。
確認: `python3 tools/dev_server.py 8791` を起動して http://localhost:8791/

「平面図」または「内観3D」を開き、画面右上（ヘッダー直下）の「床ビュー」を「天井ビュー」に切り替える。独立したダイアログ・キャンバス・3Dレンダラーは廃止。平面図は既存のパン・ズーム位置を維持し、内観3Dは既存カメラで下から天井を見る。床に戻すと通常の家具・床表示に復帰する。

- 「部屋・壁・天井」カテゴリの下げ天井／折り上げ天井を使用（既存のカテゴリ開閉・項目選択・検索を共用）。部屋作成と同じ2点指定。通常の選択・サイズ変更ハンドル・右側設定・コピー／貼付・削除・Undo／Redoを使用。
- 照明・ファンは既存の住設メニュー。天井段差の編集時は器具の相対的な取付高さを保持する。
- 内観3Dでも既存の選択・移動ギズモ・設定パネルを使用。天井面をクリックして範囲や照明を追加できる。
- 天井範囲は通常のDATA.items内のceiling-area。旧room.ceilingAreasは天井ビューへ入った際に座標を保って移行する。既存配置を削除しない。
- 平天井内の矩形に対応。段差10〜800mm、壁との離隔5mm。重複・階段吹抜け・階高超過は拒否。
- **間接照明用の溝は後回し（やらないのではない）。** 天井を凝る施主の多くはここに間接照明を仕込むので、溝は作りたい形の一つ。ただし溝だけ作っても、光の当たり方が説得力を持たないうちは魅力的に見えない。**先に間接照明が美しく見えるライティングを作り、それから溝の形状に入る。**
- 勾配天井への部分的な段差と、矩形でない多角形の天井範囲は未対応。

実ブラウザで既存キャンバス上の2点指定、設定変更、器具高さ追従、Undo／Redo、削除、コピー／貼付、旧データ移行、保存、レンダラー共有、床表示復帰、モバイル表示を検証。天井・高さ関連の回帰テスト121件を実行（ceiling-finish 29 / ceiling-ui 27 / height-defaults 12 / height-model 15 / height-wiring 31 / ceiling-fixture-height 7）。最後の7件は、天井付けの器具が天井仕上げ面に付いているかを node:vm で実際に走らせて数値で見る新規の検査。

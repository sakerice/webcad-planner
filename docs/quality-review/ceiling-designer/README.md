# 天井デザイン（専用ブランチ）

ブランチ: `codex/ceiling-design-view`。本番未反映。

ヘッダーの「天井デザイン」から開く。天井伏図は床の間取りと同じ左右・方位の向き。見上げ3Dは下から見る実際の視点で回転できる。

- 平天井の部屋内で矩形の下げ天井／折り上げ天井を描く。範囲はドラッグ移動、数値で位置・幅・奥行・段差・色を変更。
- 段差は下げが負、折り上げが正（10〜800mm）。壁との離隔5mm、範囲同士は5mm以上。重複と階段吹き抜けは作成時に拒否。
- 折り上げが階高を超えないよう検証。必要なら部屋の余白を選択して基本天井高を下げる。
- シーリングライト、ダウンライト、スポットライト、登録済みシーリングファンを配置・移動・回転・高さ変更できる。
- 範囲の段差や位置を変えると、その範囲内の器具の高さも追従する。意図的に下げてある器具の相対高さを維持する。
- 3Dでも範囲・器具をクリック選択して数値編集できる。
- 拡大／縮小・表示移動・全体表示。Undo／Redo、削除、階選択、モバイルレイアウト。
- 部屋の `ceilingAreas` にローカルmm座標で保存する。既存配置・既存プランに移行を要求しない。外観／ウォークスルーの天井にも同じ形状を適用する。

対応範囲: 矩形・平天井。勾配天井や吹き抜け内への範囲追加、壁に接する範囲、間接照明用の溝や複雑な多角形断面はまだ対象外。通常の内観鳥瞰は従来どおり天井を隠す。天井を編集・確認する場合は専用ビューを使用する。

検証: 実マウスで矩形作成・照明追加・段差変更と器具の追従・Undo/Redo・保存を確認。下げ／折り上げの両面に下からレイを当て、期待する高さを確認。PC／モバイル、天井伏図／見上げ3Dの画像を保存。既存天井の回帰テストも実行。

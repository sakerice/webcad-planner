# 2階建ての再構成 — アイランドキッチンと余白

前版の問題は、3階建てで整理された「狭い空間を家具で埋める」「通路を飾る」「用途を増やす」という配置が、2階建てには残っていたこと。玄関収納の交換だけでは不十分だった。今回、壁・部屋の区切りから見直し、アイランドを中心に組み直した。

## キッチンの設計

シンクを独立アイランド、IHを北の壁付カウンターに置く。リビング側を見て下ごしらえができ、フードは壁側へまとめられる。シンクアイランドと壁側コンロを分ける構成は[クリナップの公式施工例](https://cleanup.jp/kitchen/centro/)でも紹介されている。四周を回れる配置と、通路・調理面を先に確保する考え方は[LIXILのレイアウト案内](https://www.lixil.co.jp/lineup/kitchen/hint/layout/)を参考にした。商品形状は模倣せず、モデルは独自に制作した。

- シンクアイランド: 長さ2100×奥行900mm、天板850mm。実際に穴のあるシンク、排水口、水栓、引き出し、指掛け、後退した台輪を制作。
- 壁付カウンター: 幅2560×奥行650mm、天板850mm。IHはシンク上の窓から離し、フードと同軸に置いた。
- アイランドは南北方向。作業側の東は壁内面まで1055mm、西は955mm。北カウンターまで1035mm、南の食卓・椅子まで約966mm。4方向を壁・床置き家具が塞がないことをテストで検証。
- 冷蔵庫を北東のアルコーブへ移し、アイランド横の通路に出ないようにした。シンク・IH・冷蔵庫の作業点を使った三角形も検査対象に追加。
- 既存のキッチン区画を無理に使わず、水まわりとの境界を300mm西へ移した。洗面脱衣室・ランドリーは各1520×1820mm。洗面台・洗濯機・扉も移動し、家具の干渉と扉の開閉を確認。
- 独立した食卓をアイランドの先に配置。スツールや飾りを追加して通路を埋めない。

## 玄関・LDK・上階の変更

| 領域 | 今回の変更と理由 |
|---|---|
| 玄関〜ホール | 上がり框の壁と狭い中間廊下の壁を撤去。玄関から階段へ進み、横へ曲がってLDKへ入る構成。自由に立てる土間を確保し、鏡・鉢を床へ追加しない。 |
| LDK入口 | 一枚の開き戸と壁で絞られた部分を開放。通路からキッチン・庭方向へ自然につながる。 |
| リビング | ソファとテレビの中心をそろえ、柄物のラグと花瓶を撤去。小さなサイドテーブルを手の届く横へ。中央には机を置かず、13.25㎡の吹き抜けを残した。 |
| 家事室 | 奥行773mmの大型収納を580mmの収納へ。積み棚・飾り棚を撤去し、洗う・干す・畳むための器具を残す。 |
| 上階のギャラリー | 廊下端の910角のリネン庫と壁・折戸をなくし、廊下を連続させた。廊下の絵も撤去。 |
| 子ども室 | 年齢・性別を決めつけた玩具やラグを撤去。両室ともベッド・机・椅子・衣類収納1台とし、収納は奥行580mmに。小さい洋室Bにも机を設け、家具が重ならずドアが開く位置にした。 |
| 水まわり・収納 | 大きな装飾鏡、積み重ねた棚、コーヒー専用コーナーを整理。玄関を除く1階床150mmと、照明の正しい取付高さは維持。 |

## 変更量・検証

前版208点→172点、壁37本→34本、部屋23室→21室。上階の独立リネン庫を廊下に統合し、二つに分かれていたキッチン領域を統合した。3LDKと13.25㎡の吹き抜けは維持。

配置検査42項目通過。収納率8.3%が目安10〜13%未満という指摘は残す。面積指標のために収納家具を戻して通路を狭めることはしない。収納室の棚割りや実際の収納容量は別途検討が必要。

Python回帰14件、オリジナルモデル関連Node3件が通過。アイランド四周の通路を明示的に検証。キッチン通路の検査は、100mmグリッドが実際にある1055mmの通路を見落としていたため、25mmへ細かくした。要求する1000mm幅と検査する空き面積は下げていない。検査の自己テストでも全項目が発火した。

## モデルの出典と保存先

新規モデル2点は `tools/blender/build_island_kitchen.py` による独自制作。外部モデル・画像の取り込みはない。GLBは `assets/models/original/`、編集可能なBlenderソースは `tools/blender/work/original/`、正面・背面・上面の検証画像は `assets/models/previews-v2/`。サイト正面+Z、上+Y、木部・天板・金物の色変更を確認。既存モデルは引き続き利用できる。

建築構造・設備配管・法規適合を認証したものではない。特に移した水まわり境界と上階壁の関係は、実施設計時に構造設計で確認する。

# オリジナル家具の併用・比較

2026-09-08。既存モデルの置換ではなく、独立した6件をカタログへ追加した。

- オークフレーム ソファ / ラウンジチェア / ファブリックヘッド ベッド
- オーク ダイニングテーブル / オーク サイドボード / オーク ワードローブ

家具検索「オリジナル」で選択できる。配置後の詳細設定「素材・カラー」で張地・木部を変更し、既定色に戻せる。変更は配置ごとの `finishColors` に保存する。金物や寝具の白、他の配置、キャッシュされた元モデルは変更しない。色変更した配置は個別描画、既定色の配置は既存のインスタンス描画を使用する。

`index.html` は同じThree.js照明・カメラで撮影した既存/新作の比較表。正面側・背面側・色変更の例を切り替えられる。外部モデルの適法性や新作への全置換を承認する資料ではない。

## 制作と確認

- ソース: `tools/blender/build_original_furniture.py`、仕様: `tools/blender/original-collection.json`
- 再生成: `ORIGINAL_COLLECTION=1 /Applications/Blender.app/Contents/MacOS/Blender -b -t 6 --python tools/blender/build_original_furniture.py`
- 編集可能なマスター: `tools/blender/work/original/original-*.blend`（ローカルのworkディレクトリはGit対象外）
- 3D: `assets/models/original/original-*.glb`。独自形状と数式生成テクスチャ。外部モデルの形状・画像をインポートしていない。
- glTF前面+Z、上+Y。張地/木部のマテリアルに `finishChannel` を格納。モノクロの木肌/織り目に基底色を乗せるため、色変更で元の染色が混ざらない。
- サムネイルと上面図は実GLBをレンダリング。木目の過剰な縞、布団端の硬さを画像確認後に修正。
- `checks.json`: 形状・向き・素材変更・保存・リセット・未選択状態の検証結果。`app-coexistence.png`: 同一シーンで既存ソファと新作を併用。
- ブラウザ検証: `tools/tests/original-models.browser.mjs`。実際のモバイル用色入力とリセット操作、ブラウザ例外なしを確認。
- ローカルビルド成功、公開デプロイは実施していない。大量生成した未採用447候補はローカルに保持し、配信用ビルドには登録済み6件だけを含める。

## 評価範囲と未完了

今回の6点は、配置・形状・素材別カラーを比較して採用判断できる代表コレクション。量産した447ファイルが447種類の高品質デザインとして完成したわけではない。実機スマートフォンでのFPS/メモリ測定は未実施。

車の独自試作は、車体の曲面、ガラス周辺、灯体の一体感が参考画像の水準に未達のため、今回のコレクションには追加していない。既存の車モデルも変更していない。外部モデルを新たに採用する場合は、使用方法に適合する条件・出典・必要な表記を確認する。既存モデルに残る利用条件の未確認事項は `docs/legal/model-license-audit-2026-09-08.md` に記録している。

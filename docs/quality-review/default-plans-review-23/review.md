# plan (23) の解釈と反映

## 敷地の意味を整理

以前は砂利・芝・コンクリートの仕上げを別々の `site-rect` で表現しており、仕上げの継ぎ目まで敷地境界に見えていた。今回、2階建て・3階建てとも土地全体を一つの敷地矩形に統合した。

- 2階建て：11.375 × 13.195 m、150.093㎡。建物外壁芯の輪郭は8.19 × 7.28 m。境界から外壁芯まで北1.22m・西0.91m・東2.275m・南4.695m。北は設備側、東は植栽と玄関側、南はテラスと駐車を担う。
- 3階建て：7.28 × 11.375 m、82.81㎡。既存の室内配置は変更していない。
- 敷地内の `siteZones` は地面の仕上げ。敷地を追加したり、法規の境界を作るものではない。
- 2階建てはテラス・植栽、駐車スペース、玄関アプローチ・駐輪を分け、その他は砂利。建物部分はその上の基礎・床・外壁で示す。
- 平面図は土地全体の外周を一点鎖線と面積で明示し、各外構仕上げを用途名で表示する。設定画面で用途・表面・相対位置・幅・奥行を編集できる。保存データとAI用プラン概要にも区分を含めた。
- この敷地矩形は「建築可能範囲」ではない。建物輪郭も建築可能範囲ではない。敷地内のどこにでも建築可能と示すものではなく、今回その法規判定は追加していない。

## ユーザー編集の解釈

1. デッキの2列化：窓から出るだけの縁側ではなく、屋外で過ごす奥行きを求めた変更と解釈。4枚を維持し、幅5.2m・奥行1.8mになるよう60mm／40mmの重なりを解消した。
2. 南の2.4m目隠しと西の格子追加：道路・隣家から生活を見せない意図と解釈。高さと配置の構成を維持した。
3. 車・門柱・デッキ階段の移動：テラスと駐車、玄関経路を分ける意図と解釈。車の中心位置を維持し、重なっていた点検桝を車体の外へ移した。目隠しとの間が200mmしかなく乗降しづらかったため、敷地範囲を維持したまま建物・テラスを一体で600mm北へ移し、車の北側に800mmの通路を確保した。車は西向きに変更し、右ハンドル車の運転席がこの通路側となる構成にした。北側の外壁芯から境界まで1220mm。デッキ西の階段を端部にそろえた。
4. 主寝室のベッド反転と収納の整理：南を枕元にし、東に造り付け収納を集める意図と解釈。ベッドの向きと削除された家具を維持し、東側に650mmの通路を確保した。枕元のテーブルは幅304mmの既存モデルに替え、ランプをその天板高さに合わせた。
5. 2階東の区画変更：ホールから使うリネン収納と、寝室から使うクローゼットを分ける意図と解釈。壁端を芯にそろえ、扉を実際の壁線に合わせ、トイレ入口を修正した。

ファイル保存時の `modelFacingVersion` 更新による回転補正は、ユーザーがすべての家具を反転したとは解釈していない。保存済みの向きの情報をそのまま引き継いでいる。

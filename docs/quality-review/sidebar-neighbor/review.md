# 標準建具サムネイル・出典・隣家のレビュー

2026-09-09

標準建具5種（開き戸標準／小、引違い／FIX／掃き出し）を実際の開口生成関数から512px透過画像で生成。既存の共通カードサイズに収める。リンクはスナップ設定の兄弟要素に移し、背景・枠なしのテキストリンクとした。

隣家は既存の寸法と正面を保った独自Blenderキットの改修。新たな外部素材は不使用。窓ガラスの透明度、サッシの面取り・排水穴・クレセント、室内後退とカーテン、塗り壁と屋根の微細凹凸、半丸軒樋・端部・吊金具・呼び樋・竪樋固定金具を追加。透明表示の既存挙動を維持。

修正前後の代表形状外寸は一致。詳細レビュー用の未統合状態で86,972→112,760三角形。実際の統合後のメッシュ数が45以下であることを検証（描画時間や端末FPS保証ではない）。GLBは約2.2MB。編集可能なBlenderソースをtools/blender/work/originalに保存。

検証：sidebar-neighbor.browser.mjs（390／1280px、サムネイル5種の読込と重複なし、出典配置、透明ガラスとカーテン、半透明用マテリアル分離、詳細メッシュ統合）。build.shはSKIP_DEPLOY=1で成功。

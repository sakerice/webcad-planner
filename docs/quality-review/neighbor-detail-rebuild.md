# 隣家キット細部改修（2026-09-16）

既存の隣家ID・配置・寸法・階数を保持し、独自Blenderキットとアプリ内の組立処理を修正。

- 寄棟屋根の三角形の頂点順序が内向きだったため、上面・下面とも外向きに修正。
- 棟包み・隅棟包みを浮いた角材から、屋根面の高さに追従する折り板へ変更。屋根面から8〜14mmの仕上げとして配置する。
- 玄関庇の上の2枚の板を除去し、壁際の雨押えを追加。
- 車庫のシャッター枠と外壁の同一面を解消。車庫内部と重なっていた簡略室内ボリュームを分割し、開口内部をふさがない構成に変更。
- シャッターは横スラットを実形状で制作。奥の収納を無垢の箱から支柱・棚板のラックへ変更。
- 物干しはパラペット内側の固定プレート・ボルト・支柱・支持腕・竿を一続きの構成に変更。
- 玄関扉に埋まっていた取手を屋外側へ移し、固定部とシリンダーを追加。採光スリットをBooleanによる実開口に変更。

## 配置の判断

| 対象 | 配置と理由 |
|---|---|
| 吹抜 | 家具を置かない余白ではなく、ソファのある生活の中心に配置。上階の床が実際に存在しないことも検査する。 |
| 上階の個室 | 寝室への光・音・視線を抑えるため通常壁で独立。吹抜への開放は廊下・ギャラリーで受ける。 |
| 高窓 | 2階建ては南・西、3階建ては南・東。個室を通さずにリビングへ採光する。 |
| 上階の腰壁 | 吹抜・階段の床端を高さ1100mmの壁で囲う。家具を踏み台として壁際へ寄せない。 |
| ソファ | テレビの正面に向ける。3階建ては幅2100mmへ拡大し、背後に読書机への通路、南にバルコニーへの通路を残す。 |
| テレビと台 | テレビの正面と台の引出しが室内を向き、脚が天板へ接地する高さ。窓をテレビで塞がない。 |
| 食卓 | 調理列から配膳でき、玄関・階段からリビングへ抜ける経路を食卓の外側に取る。家具セットに含まれる椅子の占有範囲も検査する。 |
| 調理列 | 幅2560mmのシンク・調理台・コンロ。冷蔵庫を独立させ、作業面と複数人で使う通路を確保する。 |
| キッチン家電 | 実際の天板高へ接地。シンク上の窓から外し、家電が浮かないよう確認する。 |
| 読書机（3階建て） | 2階東壁へ配置。ソファ背後の通路と椅子を引く場所を分け、高窓のある空間で作業できる。南の低い収納には書類・ゲーム用品をしまう。 |
| 主寝室（2階建て） | 北の衣類収納前と、1600mm幅ベッドの両側に立つ場所を残す。入口は東の廊下から。枕元には丸いグリーンの金属テーブルを置き、ランプを高さ513mmの天板へ接地させる。 |
| 主寝室（3階建て） | 1階の独立室。寝室から使うリーチイン収納を隣接させる。南の窓は屋外の格子で道路からの視線を和らげる。 |
| 子ども室 | ベッド・学習机・椅子・衣類収納を各室に用意。3階建てでは各室に幅1000mmの衣類収納2本を置き、入口は収納の正面から外す。 |
| 玄関収納 | 靴・コート・外出用品を帰宅直後に収納できる場所へ。玄関扉と上り框の通路を空ける。 |
| 家事室 | 洗濯機に近接。天井物干し、畳む天板、洗剤・タオル収納を同じ動線上に配置。棚は実際の壁面に寄せる。 |
| 洗面・鏡 | 鏡は洗面器の正面。窓は鏡より上の高窓へ移し、鏡と窓が重ならないようにする。 |
| カーテン | 布を窓の両端へ寄せ、中央の採光を残す。モデルの布部分の実座標から外寄せを検査する。 |
| ロールスクリーン | 机・キッチンなど布の垂れ込みを避けたい場所へ。上部へ巻き上げた状態で光を残す。 |
| 室内機 | カスタムモデルの正面は＋Z。吹出口が室内を向く角度へ変換。窓装飾との高さ、居住位置への送風を確認する。3階建ての1階主寝室にも追加した。 |
| 室外機 | 独自モデルの正面＋Zを考慮し、吹出口を外へ向ける。室内機との対応、室外機同士・外構との干渉を検査する。 |
| シーリングファン | 吹抜の天井へ実寸高さで取り付ける。吹抜内の上下の空気を循環させる想定で、照明は回転範囲から外す。 |
| 照明 | 歩く場所、作業面、収納前を照らす位置へ。取り付け高は各室の実天井から計算。3階建ての食卓上は2灯のダウンライトへ変更。 |
| 小物・植栽・絵 | 台の高さと支持面がある場所、窓脇や玄関の視線の終点へ。撤去した壁に付いていた絵は撤去。経路に家具を足すための装飾は置かない。 |
| 外構 | 玄関アプローチ、駐車、自転車、デッキ、室外機を分離。隣家と道路は敷地条件の判断用に残し、今回の配置判断に不要な電柱は撤去。 |

寸法は壁芯・家具データに基づく。上記は設計意図と配置検証であり、構造計算・法適合判定・採光計算・空調負荷計算を実施したという意味ではない。大吹抜・大開口を実施設計へ進める場合は、梁・耐力壁・断熱・日射遮蔽・冷暖房能力を一体で設計する必要がある。

## 描画の根本修正

2階から3階へ抜く吹抜で、床スラブ厚180mmを二重加算し、白い天井を屋根の上へ押し上げる不具合を修正した。吹抜は床スラブ下端から高さを算出済みなので、通常の明示天井と同じ加算をしない。目標階の天井との一致と、照明取付高5208mmを回帰テストで検証する。

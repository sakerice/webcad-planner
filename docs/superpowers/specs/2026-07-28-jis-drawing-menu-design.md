# JIS図面出力メニュー 設計書

日付: 2026-07-28
ステータス: 承認済み(ユーザー確認済み)

## 目的

白黒の書類として使える、JIS製図規格(JIS A 0150 建築製図通則)に沿った
平面図(間取り)と東西南北4方位の立面図を表示・印刷・ダウンロードできる
メニューを追加する。ツールバーの「🎥 AIレンダー」の隣に配置する。

## 決定事項(ユーザー回答)

- 出力形式: 画面表示+印刷/PDF両対応(モーダルでプレビュー、ブラウザ印刷とPNG/SVGダウンロード)
- 平面図の内容: 寸法線(外形・通り芯)、部屋名・畳数、階段・設備記号を含む。可動家具は含めない
- 生成方式: 平面・立面ともSVGベクター生成(3D正投影キャプチャは不採用)

## UI

- ツールバーの `#unity-render-toolbar-btn`(AIレンダー)の直後に
  `📄 JIS図面` ボタンを追加(`mob-hide`、`openJisDrawingDialog()`)
- 全画面モーダル(既存モーダルのCSSパターンを踏襲):
  - 左ペイン: 図面リスト。平面図はデータの存在する階のみ(1F〜4F)、
    立面図は東・西・南・北の4面
  - 中央: 選択中図面のSVGプレビュー(白背景、ズーム可)
  - 上部バー: 縮尺選択(自動/1:50/1:100/1:200)、用紙(A3横/A4横)、
    `🖨 印刷/PDF` `⬇ SVG` `⬇ PNG` ボタン、閉じるボタン
- 印刷: 選択中図面(または全図面一括)を `@page` CSS付きの印刷用HTMLとして
  hidden iframe に書き出し `iframe.contentWindow.print()`。
  ブラウザの印刷ダイアログからPDF保存できる
- PNG: SVGを `Image` → canvas 経由でラスタライズ(長辺約3000px)して保存

## 平面図仕様

- 線幅体系(JIS A 0150 の太/中/細の3段階):
  - 極太線+黒塗り: 壁断面(既存 `drawWall2d` と同じ考え方)
  - 中線: 建具記号、設備記号、階段
  - 細線: 寸法線、引出線、畳数文字、方位記号
- 開口記号: 引違い(2本レール+互い違い建具線)、FIX、開き戸(1/4円軌跡)、
  掃き出し窓。既存2Dキャンバス描画のジオメトリ計算
  (`getOpeningWallInfo` 等)を利用しSVGに出力
- 階段: 段板+登り方向矢印(UP/DN)+破断線
- 設備記号: キッチン(コンロ・シンク簡略)、浴槽、便器、洗面の簡略線画。
  対象は items の該当タイプのみ。可動家具(ソファ・ベッド等)は描かない
- 部屋名+畳数: 各 room の中央に「名称 / N.5帖」形式。面積は room の w×d から
  1帖=1.62㎡で換算
- 寸法線: 外周2段(全体寸法+主要壁芯間隔)。mm表記、端部は黒丸または斜線
- 方位記号: 北矢印(2D画面の上=北とする)
- 表題欄: 右下に図面名・階・縮尺・日付の枠

## 立面図仕様

4方位(東西南北)それぞれの正投影をDATAから直接計算する。

- GL線(地盤)、基礎立上り(foundation の高さ)
- 外周壁シルエット: 対象階の壁を方位軸に投影し、区間結合して外形を作る。
  壁ごとの `wallHeight` と階レベル(`FLOOR_H`、基礎高)を反映
- 開口: 窓(sill+高さから矩形、窓種で内部線を変える: 引違いは縦中桟、
  FIXは対角細線等)、ドア。**その方位に面した壁の開口のみ**描く
- 屋根: roofType 7種(gable / gable-y / hip / hip-ridge / hip-ridge-long /
  flat / mono)ごとに、見る方位に応じた投影プロファイル(三角形・台形等)を計算
- バルコニー・フェンスは簡略輪郭のみ
- 高さ寸法: GL、軒高、最高高さの3点を図面右側に記載
- 隠線処理は簡略化: 「外形シルエット+その面に面した開口」のみ。
  奥の壁や内部は描かない(一般的な意匠立面図レベル)

## 実装構成

- `index.html` 内に独立セクション「JISDRAW モジュール」を追加
  (IIFEで名前空間を閉じ、SVG文字列を生成して返す純粋関数群+モーダルUI)
- 既存コードへの変更: ツールバーのボタン1個追加、モーダルHTML追加のみ。
  既存関数・データ構造は読み取りのみで変更しない
- 主要関数(予定):
  - `JISDRAW.buildFloorPlanSvg(floor, opts)` → SVG文字列
  - `JISDRAW.buildElevationSvg(direction, opts)` → SVG文字列
  - `openJisDrawingDialog()` / 印刷・DLハンドラ
- 縮尺「自動」は建物範囲と用紙サイズから 1:50/1:100/1:200 のうち
  収まる最大縮尺を選ぶ

## エラー処理・エッジケース

- 壁が1枚もない階は図面リストに出さない。全階空なら開いた時に案内文を表示
- 屋根 item が無い場合、立面図は壁上端(パラペットなし)までを描く
- 傾いた壁(軸に平行でない壁)は平面図はそのまま描画、立面図は投影で自然に対応
- SVG内の日本語テキストはシステムフォント指定
  (印刷・PNG化でも文字化けしないよう font-family を明示)

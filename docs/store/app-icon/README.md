# アプリのアイコン

2026-11-26 に利用者が決めました。

| ファイル | 役割 |
|---|---|
| `AppIcon-1024.png` | App Store とホーム画面に出すアイコン。今の配色（白地に朱色の家と青い指）を、規定の 1024×1024・透過なし・角丸なしにした物 |
| `AppIcon-inverted-1024.png` | サブアイコン。朱色と白を入れ替えた版で、手の白い縁取りは残してある。色の付いた地が要る場面（X のプロフィール画像、告知の絵、白い背景に置く場面）で使う |
| `AppIcon-inverted-alt-1024.png` | 反転の別版（手の縁取りまで朱色）。手が地にくっついて見えるので使わない。比較の記録 |
| `compare-sizes.png`・`compare-home.png` | 180px〜29px へ縮めた比較と、ホーム画面に置いた比較 |
| `make_icons.py` | 元の絵 `assets/brand/house-planner-mobile-icon.png`（1254×1254）から上の 3 枚を作り直す道具。絵は描き直さず、画素の色を変換している |
| `candidates/` | 1 回目に出した描き直しの案（A・A2・B・C）。採っていない |

## 決めていないこと

- サブアイコンを、アプリの中で利用者が切り替えられる別アイコン（alternate app icon）としても入れるか。入れる場合は、その分のダーク・クリア・ティントの版を自分で用意する決まりです（`checklist.md` のアイコンの節）。初版では入れず、アプリの外の用途にだけ使う前提にしています。
- ダーク・クリア・ティントの版を自分で作るか。出さなければシステムが自動で作ります。

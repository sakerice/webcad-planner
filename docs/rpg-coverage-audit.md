## 次の優先順

1. 支持面と座面：現在のGLBから座面・天板・寝面・棚面を測る。`assetRevision=sha256` に結び付け、既存v0.1 sidecarとは別revisionに候補として出す。TPSの姿勢・足元・進入・衝突を実機検証するまでは `geometry-candidate-host-validation-required` のまま。非一様scaleの法線はinverse transpose、支持点と領域はitem world matrixで変換する。
2. キッチン／水回り：流し・調理炉・食器棚、浴槽・洗面台・便器は現存するが給排水接続、蛇口操作、冷蔵、壁付けは未対応。冷蔵庫を保冷庫へ変換しない。必要機能・設置方法ごとの対応表を先に確認する。
3. 寝室／書斎／収納：ベッド2種、机類、本棚・箪笥類はある。寝面と机の作業面、引出し開閉、コーナー収納、二段ベッド、収納一体型の形状差を検証する。装飾の増産より生活用途の欠けを優先。
4. カーテン／照明：両開き1種、床・卓上・壁・天井の灯具は存在。窓幅/壁面法線、取付高さ、照明機能は別契約で検証する。灯具GLBは装飾であり照明効果を自動追加しない。
5. 外構／階段：洋館packには階段・扉窓・屋外動線の対応がない。既存の構造部材と階段をそのまま使い、レベル間移動、手すり、衝突、出口の契約が決まるまで置換しない。

向きは全50点の +Y up / +Z front / bottom centre とmanifest寸法を検証済み。新36点のseat/support sidecarはまだ追加していない。旧14点の既存提案は保持。高さ修正と17点の幾何品質修正を独立レビューしてから、上記候補の測定と実機接続検証を進める。

## 性能と残りの検証

50点のGLB合計2,634,484bytes、68,402triangles。カタログ切替は既存配置やGLB cacheを変更せず、候補一覧のみを切り替える。既存の100回切替テスト、遅延GLB3ケースに加え、高さ修正後の比較画像生成キャンセルを実ブラウザで再確認した。GLB loader自体は別作業のため変更していない。`asset-pack-load-performance.browser.cjs` でHTTP cacheを無効にした新規Chromium contextから50モデルをロードし、50リクエスト・172.2msを記録した。同じページのwarm cacheを5,000回参照して追加リクエスト0・1.6ms。これはlocalhost上のloader/decode/material準備の測定で、描画フレーム時間や物理モバイルGPUの評価ではなく、速度改善を主張しない。

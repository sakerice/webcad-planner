# Rights and provenance

All 18 new model IDs are original procedural geometry authored for this project in Blender. No external geometry, downloaded texture, stock photo, font outline or third-party image is embedded in the models. Surface colours and material channels are numerical PBR values. The native source helpers are locally copied original project authoring helpers.

Eight earlier original project models are bundled solely as explicit hash-bound dependencies for installed assembly proof. They retain their earlier identities and are excluded from the new-model count.

The new assets are reconstructed creations, not recovered historical binaries. Earlier acceptance or binary hashes are not transferred to these new files. See rights-registry.json and the final current-byte validation records for each asset.

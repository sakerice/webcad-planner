# Original water-room prototypes

Work in progress, isolated from the accepted 171 models and all application data.
Three prototype construction roles are being authored: high-backed hollow slipper
bath; genuinely bracket-supported wall basin; high-cistern pull-chain WC with its
own wall brackets. No prototypes are accepted or counted yet.

The wider candidate family has 18 roles in the water plan. Symmetric roll-top bath,
pedestal washstand and low-coupled WC already have baseline representatives. Any
later example of those roles must demonstrate new construction, not rename,
recolour or uniform rescale existing geometry. Source dimensions are demand
references only; implausibly small tags are not bathing-envelope targets.

Native parts are authored in metres, +Z up and -Y front, with named ceramic,
metal, wood and other actual finish channels. Canonical export is exactly one
mesh, bottom-centred by translation only, with GLB +Y up and +Z front. Fixtures
and capacity are static design representations, without working plumbing or
ergonomic/engineering certification. The installation walls/floors and section
views are labelled QA fixtures, not model assets.

Run build.py in Blender background mode. Run render_batch.py against reopened
canonical sources. Local QA and an independent final-byte review are required
before parent review and acceptance. Root owns uploads and delivery.

# Original-work record

Eight original static architecture modules were authored specifically for this project using native Blender mesh construction: planar prisms and polygon sweeps, mitered panel frames, a hollow roof deck with distinct slate plates, fitted gable closure, profiled cornices and a turned Tuscan-style column.

No external meshes, scanned geometry, image textures, downloaded asset packs, reference-image tracing or imported third-party models were used. Material colours and PBR factors are original procedural values. Blender is the authoring/export tool; shared project Python helpers provide primitive construction, material creation and export functions, not imported asset geometry.

Creator: OpenAI assistant working for the project user. Rights basis: original procedural geometry and materials created for this project. Each descriptor records the same provenance, empty external-source list and source hashes. No claim of exclusive ownership over generic historic architectural forms is made.

The three assemblies reuse these eight assets at unchanged physical size and orientation-compatible rigid placements. Their repeated instances and the explicitly labelled front QA filler fixture are not additional catalog assets. Corrections to substrate interfaces and gable shoulders are revisions of the same originals, not new asset counts.

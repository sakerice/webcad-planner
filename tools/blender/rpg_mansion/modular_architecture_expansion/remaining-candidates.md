# Remaining construction-role checks, pending initial assembly review

Sixteen proposed families remain. These are design assessments, not built or accepted assets. A changed dimension or color alone will not earn another construction count.

1. Ashlar wall bay: real staggered masonry face units over a continuous wall body, keeping the same wall datum and band joins.
2. Rusticated plinth: a grounded foundation/base segment with a level wall-bearing top and actual rustication recesses; different installation/support role from a full wall.
3. Half-timber infill bay: fitted stiles, rails and nonoverlapping diagonal braces around plaster fields; preserve exact wall-edge section joins.
4. Tall fixed French-window bay: full-height threshold-supported paired fixed frames with an upper transom, rather than a stretched raised-sill four-pane bay. If implementation proves to be only proportional, label it a variant and do not count it separately.
5. Octagon/cabochon floor: real polygonal stone slabs and fitted contrasting diamond cabochons over a continuous substrate; test both horizontal repeats.
6. Hipped gable-roof end: use the frozen gable span's actual 0.7 pitch, deck section, bearings and slate phase. This is a closure for that existing system, not another mansard shape.
7. Conical turret roof: a hollow radial roof shell with an explicit circular bearing ring and real slate courses. Demonstrate supported bearings with actual modules; do not imply a circular wall module exists.
8. Flat/parapet roof: a useful genuinely supported flat deck and parapet construction with explicit corner/run mating or an honestly bounded full-cap role. Any required edge-width options remain variants.
9. Standing-seam lean-to: a hollow single-slope deck with physical folded seams and explicit low/high support datums. Do not place it on incompatible equal-height walls or hide support gaps.
10. Pilaster: an attached square wall-support construction with base, shaft and capital datums, distinct from the frozen round Tuscan column. Prove the wall/cornice relationship with actual module geometry.
11. Stone newel: a grounded railing endpoint with separate footing, shaft and cap; record actual connector levels.
12. Stone balustrade: continuous top/base rails and turned infill supports, compatible with the actual newel endpoints.
13. Wrought-iron railing: fitted metal uprights and scrollwork with real supported rail endpoints; not a material swap of the stone balustrade.
14. Chimney: hollow flue(s), crown/caps and explicit installation support. Any roof penetration must be a real compatible host opening or the limitation must be explicit.
15. Dormer/host section: a genuine glazed dormer paired with an actually open matching host roof. If that cannot be made and tested, it must instead be labeled a closed decorative prop, with no see-through or roof-cutting claim. A paired host does not silently inflate the planned construction-family count.
16. Portico pediment: an actual supported triangular entablature/pediment and matched base/cornice bearings, distinct from the existing between-bearing gable closure.

Additional sources, helper code and files remain in this isolated tree. Final acceptance requires measured joins, local part support, strict corner normals, real UV triangle overlap tests, source/PBR replay, source privacy, view margins and exact fresh pixel replay. No deployment, shared manifest, finish-library application or remote operation is included.

# Original asset rights and source record

All nine initial assets are original procedural native Blender geometry authored for this mansion-kit expansion. No external model, photograph, image texture, stock asset, or paid service was used. Current simple PBR colors are native materials; the separately proposed finish library is not imported or applied.

Each descriptor records original provenance, empty external source lists, named native source paths, canonical model/source hashes, and rendered-view hashes. Geometry-building code, source files, render recipes, connection contracts and measurements are included in the review package. Frozen first-eight helper copies retain their original byte hashes in `immutable-helper-copies.json`; modified derivatives use explicit expansion names.

The 600 mm plaster filler is a width-only variant of the plain bay and is not counted as a separate original construction family. Repeated assembly instances, rendered images, source variants and QA outputs add no model count.

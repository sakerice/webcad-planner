# 読み取りの再現度を測る（計画の 0-3）

間取り図からの下書きが、正解にどれだけ近いかを点数にする道具。
モデルの切り替え・指示文の変更・切り出しの変更は、ここで点数が上がったものだけを取り込む。

| ファイル | 役割 |
|---|---|
| `fixtures.json` | 正解付きの図面の一覧。図面・正解・図面の画素と mm の対応 |
| `truth/` | 正解プラン（アプリに保存される形）と、それを作るスクリプト |
| `score.cjs` | 正解と読み取り結果を比べて点数を出す（AI は呼ばない） |
| `overlay.py` | プランを元の図面に重ねて描く。正解の確認と、外れた所の確認に使う |
| `run.mjs` | アプリの画面で図面を読ませ、取り込んだ間取りを採点する |
| `measure.sh` | 手元に本番と同じ Worker を立てて `run.mjs` を1回回す |

## 点数

総合 = 壁 40% + 部屋 30% + 建具 30%（各階の平均、0〜100）。

- **壁** … 正解の壁のうち読み取りが重なっている長さの割合（取りこぼし）と、読み取りの壁のうち正解に重なる割合（余計な壁）の調和平均。芯のずれ 150mm までを同じ位置とみなす（50mm での点も併記）
- **部屋** … 重なり（IoU 0.3 以上）で対応づけ、数（対応の取れた割合）・名前・面積の3つの平均。L字は同じ名前の長方形をまとめて1室。名前は畳数・丸数字の書き方の違いを無視し、用途が同じなら半分の点
- **建具** … 窓どうし・扉どうしで中心が 600mm 以内のものを対応づけ、数と位置の平均。種類まで一致したか（引き戸を開き戸と読んでいないか）は別に表示

原点は図面ごとに違うので、平行移動だけは採点側で合わせる（回転・反転はしない）。

## 使い方

```bash
# 採点だけ（AI を呼ばない）
node tools/plan-eval/score.cjs tools/plan-eval/truth/madori-3f.json <読み取ったプラン.json>

# 図面に重ねて見る
python3 tools/plan-eval/overlay.py madori-3f <プラン.json> /tmp/check

# 1回測る（AI の費用がかかる。回数は先に決める）
bash tools/plan-eval/measure.sh madori-3f openai-1 openai gpt-6-astra
bash tools/plan-eval/measure.sh madori-3f opus-1 anthropic claude-opus-5-5 high
```

結果は `out/<図面>/<名前>.json`・`.txt` に残る（コミットしない）。
`run.mjs --fake` は AI を呼ばずに正解を返し、画面〜採点の配線だけを確かめる（満点になる）。

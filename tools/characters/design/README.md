## 制作と採用理由

正式なOpenAI `image_gen.imagegen` とimagegen技能を使用した。生成、方向展開、修正、三面図の構成まで同ツールで行い、手描きやコード描画による代用をしていない。ツールは基盤モデル名・版を返さなかったため、モデル名を断定していない。実際に送った初回・修正・三面図の指示全文は [generation-prompts.json](generation-prompts.json)。外部の作品画像、既存キャラクター画像、写真を入力していない。参照編集にはこの依頼で生成した自分の候補だけを用いた。作品名・キャラクター名を生成指示へ入れていない。

住宅の住まい手として大人と読める肩幅・体格、約6.2〜6.4頭身の抑えたアニメ表現を採用した。男性は無地のニットとチノパン、女性はボタンのないカーディガンとAラインスカート。簡単な輪郭と控えめな表情、中間色の服で、肌・髪・服・靴下の区分が読み取れる。色表は採用画像から採った代表色で、生成指示の指定色と実画素を混同していない。

## 画像を見て直したこと

- 男性初稿は約7.5頭身に見えたため、頭部と脚・胴の比率を複数回調整した。女性正面の頭部、男女横顔の頭部も正面との照合で調整した。採用正面の頭頂〜顎と頭頂〜靴下底の比は男性約6.2、女性約6.4。髪先や顎の手動読取による概算。
- 初稿の正面・背面は腕の開きが狭かった。肩を固定して腕・手を横へ広げ、肩中心から手首中心への線で約35〜41度（鉛直線基準）のAポーズへ修正した。横も同じ横方向の開きの投影になるよう手首の高さを修正し、修正版から三面図を更新した。
- 男性横で正面より頭が小さく見えたため拡大した。女性横も最終照合で頭を少し拡大し、三面図の中央を更新した。
- 男性の靴下に足趾を連想させる線が出たため、横画像に足先の単純化を指示した。採用画像にも少量の線画の凹凸は残るが、足先全体は靴下色で覆われ、素足の肌色は描かれていない。
- 髪型、首・袖口・裾、チノパンの丈、スカートの丈、靴下の高さ・色味を各方向で再確認した。女性背面へインナーが出ず、ボタン・ポケットが増えていない。セル塗りの折り目・陰色には方向ごとの小さな違いがあり、立体化時の基本色は色表に従う。

## 実施した検査

2026-10-13、採用PNG8枚を実際に表示して確認した。全身・顔/後頭部・手・靴下が収まり、床・落ち影・文字・ロゴ・装飾柄がない。背景は無地の明灰色に見える（生成による微細な画素差があり、背景の全画素が単一RGBであるとは主張しない）。横は左向きの側面、背面に顔を描いていない。成人の体格、部位の分離、方向間の髪型・服・丈・配色を照合した。袖や裾の陰影の画素まで一致する機械的な三次元正投影図ではない。

`verify-images.py` は画像を変更せず、PNGの完全デコード、単体の1024×1024以上、概算の余白・全身サイズを検査する。実行結果は [inspection.json](inspection.json)。PNG8枚のSHA-256も記録する。見た目の検査はこのスクリプトの代わりに実施している。

```sh
python3 tools/characters/design/verify-images.py
node --test tools/tests/asset-sets.test.cjs tools/tests/walk-spawn.test.cjs tools/tests/walk-unstick.test.cjs
git diff --check
```
